### 👨‍💻 About Me

I am a **Senior Cloud & Systems Engineer** specializing in enterprise endpoint management, identity governance, network threat defense, and infrastructure automation. My work focuses on building resilient open-source tools across cybersecurity, media orchestration, and modern cloud architectures.

- 🛡️ **Creator of [AegisDNS](https://github.com/digdast/aegisdns)**: Next-gen recursive DNS resolver, RFC 8484 DNS-over-HTTPS (DoH), and threat defense engine with an executive cyber command center. A modern, high-performance alternative to Pi-hole and AdGuard Home.
- 🚀 **Creator of [Pulsearr](https://github.com/digdast/pulsearr)**: Asynchronous Python media PVR unifying Sonarr, Radarr, and Prowlarr into a single ultra-fast daemon.
- 🎬 **Creator of [Renamarr](https://github.com/digdast/renamarr)**: High-velocity IMDb-powered media organizer with remote CLI agent, cross-platform UI, and recursive SMB/NFS renaming.
- 📦 **Proxmox Cluster Suite**: Automated multi-node hypervisor tuning, K3s on LXC orchestration, and real-time telemetry dashboard.
